### ⚔️ The operator

Came from the future of persuasion — years writing copy that moves human readers — to the timeline where the reader is a machine with tool access. **Prompt injection is copywriting with a model on the other end.**

Background in classic web security. Now 100% dedicated to AI security: **indirect prompt injection, agentic exploitation, LLM red teaming**.
