# SAUVAGESECURITY

**Copywriter turned security researcher.** Years of writing persuasion for humans turned out to be training for writing it for machines — prompt injection is copywriting with a model on the other end.

Background in classic web security, now 100% dedicated to AI security: **indirect prompt injection, agentic exploitation and LLM red teaming**.

---

### What I work on

- **Indirect prompt injection (IPI)** — attacks that arrive inside the content an agent reads, not in what the user types
- **Agentic attack surfaces** — what breaks when LLMs get tools: inboxes, file systems, calendars, CI pipelines
- **Extraction & exfiltration mechanics** — system prompt extraction, data exfil through an agent's own output channels
- **Judged environments** — how automated graders and refusal classifiers shape what actually works
